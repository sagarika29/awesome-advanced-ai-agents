# OGs of Tech Mobile Shell

Expo React Native app for the persona operating system.

## Setup

```bash
cd apps/mobile
npm install
```

## Run

Start the Python API first from the repo root, then:

```bash
npm run start
```

For Android emulator, the app defaults to `http://10.0.2.2:8000`.
For iOS simulator or web, it defaults to `http://localhost:8000`.

Override with:

```bash
set EXPO_PUBLIC_API_URL=http://YOUR_MACHINE_IP:8000
```
